# Scalaの「lazy」について - 遅延評価の活用法

## 概要
Scalaの「lazy」は、遅延評価を実現するためのキーワードです。この機能を使用することで、変数や値が初めて参照されたときにのみ計算されるようになります。これにより、不要な計算を避け、プログラムの効率性を向上させることができます。

## ドキュメンテーション
### 目的
「lazy」は、計算を遅延させることにより、リソースの消費を最小限に抑えたり、計算コストの高い操作を必要なときだけ実行したりするために使用されます。

### 使用法
「lazy」を使用するには、変数宣言の前にキーワード「lazy」を付けます。これにより、その変数は遅延初期化されることになります。

#### 例:
```scala
lazy val lazyValue: Int = {
  println("計算中...")
  42
}
```

上記の例では、`lazyValue`が参照されるまで「計算中...」は出力されません。このように、初めて参照された際に、計算が行われます。

### 詳細
- **初回評価**: `lazy val`は初めてアクセスされたときにのみ評価され、その結果がキャッシュされます。以降のアクセスでは、キャッシュされた値が使用されます。
- **スレッドセーフ**: `lazy val`はスレッドセーフであり、複数のスレッドから同時にアクセスされても、初回評価は一度だけ行われます。
- **無名関数との併用**: `lazy`は、無名関数（ラムダ式）と組み合わせて使うことも可能です。

## 例
以下に「lazy」を使用した基本的な例を示します。

### 例1: 遅延計算
```scala
lazy val expensiveComputation: Int = {
  println("高コスト計算を実行中...")
  1000 * 1000
}

println("まだ計算を呼び出していません。")
println(expensiveComputation)  // ここで計算が実行される
println(expensiveComputation)  // ここではキャッシュされた値が使用される
```

### 例2: 無名関数と組み合わせ
```scala
lazy val factorial: Int => Int = (n: Int) => {
  if (n == 0) 1 else n * factorial(n - 1)
}

println(factorial(5))  // 初回評価で計算される
```

## 説明
### 一般的な落とし穴
- **遅延評価の見落とし**: `lazy val`を使用すると、いつ計算が行われるかを理解しておくことが重要です。期待するタイミングで結果が得られない場合があります。
- **メモリ使用量**: `lazy val`の値が大きい場合、初回評価時に多くのメモリを消費する可能性があります。計算結果を保持するため、注意が必要です。

### 注意点
- `lazy val`は、単一の評価を保証しますが、評価が重い場合は、その影響を考慮する必要があります。
- デバッグ時には、遅延評価のために出力が意図したタイミングで表示されないことがあります。

## 一行要約
Scalaの「lazy」は、変数の遅延評価を実現し、計算を必要なときだけ実行するための強力な機能です。
