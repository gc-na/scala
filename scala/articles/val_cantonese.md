# Scala 中的 val：不可變變量的定義

## 概要
在 Scala 編程語言中，`val` 是用於定義不可變變量的關鍵字。透過使用 `val`，開發者可以創建一個在初始賦值後不會再改變的變量，這有助於提高代碼的安全性和可讀性。

## 文檔
### 目的
`val` 的目的在於創建一個不可變的數據結構，這意味著一旦變量被賦值，其值不可以被重新賦值。這樣的特性使得程序在運行時更為穩定，減少了意外修改變量的風險。

### 使用方法
在 Scala 中，使用 `val` 定義變量的語法如下：
```scala
val variableName: DataType = initialValue
```
- `variableName` 是變量的名稱。
- `DataType` 是變量的類型（可選，Scala 會自動推斷）。
- `initialValue` 是變量的初始賦值。

### 詳細說明
- 定義的 `val` 變量一旦賦值後就不能改變。如果嘗試重新賦值，編譯器會報錯。
- `val` 變量可以是任何數據類型，包括基本類型（如整數、浮點數）和複雜類型（如列表、映射等）。
- 這種不可變性使得並發編程變得更加簡單，因為多個線程可以安全地訪問同一變量而不會導致數據競爭。

## 示例
以下是一些使用 `val` 的基本示例：

```scala
// 定義一個整數變量
val age: Int = 30

// 定義一個字符串變量
val name: String = "Alice"

// 定義一個列表變量
val numbers: List[Int] = List(1, 2, 3, 4, 5)

// 嘗試重新賦值將導致編譯錯誤
// age = 31  // 這行會報錯
```

## 解釋
- **常見陷阱**：初學者可能會誤認為 `val` 變量是完全不可變的，實際上，對於某些複雜數據類型（例如集合），其內容可以發生改變，但變量的引用本身不可重新賦值。
- **注意事項**：在使用 `val` 定義集合時，雖然集合的引用不可變，但其內部元素仍然可以被修改。例如，對於一個可變的集合（如 `ArrayBuffer`），可以通過方法修改其內容，但不能將其指向另一個集合。

## 一句總結
在 Scala 中，使用 `val` 定義的變量是一個不可變的數據結構，增強了代碼的穩定性和可讀性。
