# Scala 中的 "if" 條件語句使用指南

## 摘要
在 Scala 中，"if" 條件語句用於執行基於布林表達式的條件邏輯，是控制程序流的重要工具。

## 文檔
"if" 語句是 Scala 中的一個基本控制結構，它允許開發者根據特定條件執行不同的代碼塊。若條件為真，則執行相應的代碼；否則，可以選擇執行其他代碼或不執行任何操作。

### 目的
"if" 語句的主要目的是控制程式的執行流，幫助實現條件邏輯。這使得開發者能夠根據不同的條件來決定執行的代碼。

### 使用方式
基本語法如下：
```scala
if (條件) {
  // 當條件為真時執行的代碼
}
```
若需要在條件為假時執行其他代碼，則可以使用 "else"：
```scala
if (條件) {
  // 當條件為真時執行的代碼
} else {
  // 當條件為假時執行的代碼
}
```
還可以使用 "else if" 來處理多個條件：
```scala
if (條件1) {
  // 當條件1為真時執行的代碼
} else if (條件2) {
  // 當條件2為真時執行的代碼
} else {
  // 當所有條件都為假時執行的代碼
}
```

## 示例
以下是一些基本的使用範例：

### 單一條件
```scala
val x = 10
if (x > 5) {
  println("x 大於 5")
}
```

### 使用 else 語句
```scala
val y = 3
if (y > 5) {
  println("y 大於 5")
} else {
  println("y 小於或等於 5")
}
```

### 使用 else if
```scala
val z = 7
if (z < 5) {
  println("z 小於 5")
} else if (z < 10) {
  println("z 在 5 和 10 之間")
} else {
  println("z 大於或等於 10")
}
```

## 解釋
在使用 "if" 語句時，開發者應注意以下幾點：

- **布林表達式**：條件必須返回布林值 (true 或 false)，否則會產生編譯錯誤。
- **代碼塊**：如果只有一行代碼，可以省略大括號，但為了提高可讀性，建議始終使用。
- **返回值**：在 Scala 中，"if" 語句可以返回值，這意味著可以直接將其用於變量賦值。
  ```scala
  val max = if (a > b) a else b
  ```

## 單行總結
"if" 條件語句是 Scala 中執行條件邏輯的基本工具，允許開發者根據布林條件控制程式流。
