# Scala의 try: 예외 처리를 위한 강력한 도구

## 개요
Scala에서 `try`는 예외를 처리하기 위한 기본 구조로, 프로그램 실행 중 발생할 수 있는 오류를 관리하고 안정성을 높이는 데 사용된다. `try` 블록 내에서 발생한 예외를 `catch` 블록에서 캡처하고, 필요 시 `finally` 블록을 통해 후처리를 수행할 수 있다.

## 문서화
`try`는 Scala에서 예외 처리를 위해 사용하는 기본 키워드로, 특정 코드 블록에서 발생할 수 있는 예외를 처리하기 위해 사용된다. `try` 블록 내의 코드가 실행 중 오류가 발생하면, 해당 오류를 처리하기 위해 `catch` 블록이 실행된다. 이와 함께 `finally` 블록을 사용하면, 예외 발생 여부와 상관없이 실행해야 할 코드도 포함할 수 있다.

### 사용법
```scala
try {
  // 예외 발생 가능성이 있는 코드
} catch {
  case e: ExceptionType => 
    // 예외 처리 코드
} finally {
  // 항상 실행되는 코드
}
```

### 세부사항
- `try` 블록: 예외가 발생할 수 있는 코드를 포함합니다.
- `catch` 블록: 특정 예외를 처리하는 코드 블록입니다. 여러 개의 `case`를 통해 다양한 예외를 처리할 수 있습니다.
- `finally` 블록: 예외 발생 여부와 관계없이 반드시 실행되는 코드입니다. 주로 자원 해제와 같은 작업에 사용됩니다.

## 예제
### 기본 사용 예
```scala
import java.io._

try {
  val source = Source.fromFile("nonexistent.txt")
  val lines = source.getLines().toList
  println(lines)
} catch {
  case e: FileNotFoundException => 
    println("파일을 찾을 수 없습니다.")
} finally {
  println("파일 처리 완료.")
}
```

## 설명
`try` 블록에서 발생하는 예외를 적절히 처리하지 않으면, 프로그램이 비정상적으로 종료될 수 있다. 따라서, 예외 처리는 매우 중요하다. 몇 가지 일반적인 실수는 다음과 같다:

1. **모든 예외를 포괄하는 catch**: 너무 일반적인 예외를 잡는 것은 문제의 원인을 파악하기 어렵게 만들 수 있다.
2. **finally 블록의 사용**: `finally` 블록에서 무한 루프를 만들거나 예외를 발생시키면, 프로그램의 흐름이 예기치 않게 변할 수 있다.
3. **예외 무시**: catch 블록에서 예외를 단순히 출력하고 무시하는 것은 좋은 습관이 아니다. 적절한 대처가 필요하다.

## 한 줄 요약
Scala의 `try`는 예외 처리를 위한 구조로, 오류 발생 시 안전하게 코드를 실행하고 관리할 수 있는 강력한 도구이다.
