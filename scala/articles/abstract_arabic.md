# الكلمة المحجوبة (abstract) في لغة سكالا: مفهوم واستخدامات

## ملخص
تعتبر الكلمة المحجوبة "abstract" من المفاهيم الأساسية في لغة سكالا، حيث تُستخدم لتحديد الفئات (classes) أو الدوال (methods) التي لا تحتوي على تنفيذ كامل وتحتاج إلى أن تُورث (inherit) من قبل فئات أخرى.

## الوثائق
### الغرض
تُستخدم الكلمة المحجوبة "abstract" في سكالا لتحديد الفئات والدوال التي لا تحتوي على تنفيذ كامل، مما يسمح بإنشاء هياكل أساسية يمكن توسيعها من قبل فئات فرعية. تُعتبر الفئات المحجوبة فئات غير مكتملة، بينما تُعتبر الدوال المحجوبة دوالًا يجب أن تُنفذ في الفئات الفرعية.

### الاستخدام
- **الفئات المحجوبة**: تُعلن باستخدام الكلمة "abstract" قبل تعريف الفئة. لا يمكن إنشاء كائنات من الفئات المحجوبة مباشرة.
- **الدوال المحجوبة**: تُعلن داخل الفئات المحجوبة، وتُستخدم لتعريف واجهات يمكن للفئات الفرعية تنفيذها.

### التفاصيل
عند استخدام الكلمة المحجوبة، ينبغي مراعاة النقاط التالية:
- لا يمكن للفئة المحجوبة أن تُنشئ كائنات منها.
- يجب أن تحتوي الفئات الفرعية على تنفيذ كامل للدوال المحجوبة.
- يمكن استخدام الكلمة "abstract" مع الخصائص (fields) إذا كان هناك حاجة لتعريفها دون تقديم قيمة.

## أمثلة
### مثال على فئة محجوبة
```scala
abstract class Animal {
  def makeSound(): Unit  // دالة محجوبة
}

class Dog extends Animal {
  def makeSound(): Unit = println("Woof")  // تنفيذ الدالة
}

class Cat extends Animal {
  def makeSound(): Unit = println("Meow")  // تنفيذ الدالة
}
```

### مثال على دالة محجوبة
```scala
abstract class Shape {
  def area(): Double  // دالة محجوبة
}

class Circle(val radius: Double) extends Shape {
  def area(): Double = Math.PI * radius * radius  // تنفيذ الدالة
}
```

## الشرح
- **الأخطاء الشائعة**: من الأخطاء الشائعة استخدام الفئة المحجوبة دون توفير تنفيذ كامل للدوال المحجوبة في الفئات الفرعية، مما يؤدي إلى أخطاء وقت التشغيل.
- **ملاحظات إضافية**: يجب أن تكون الفئات التي تحتوي على دوال محجوبة دائمًا فئات محجوبة، حيث لا يمكن أن تحتوي على تنفيذ كامل للدوال المحجوبة.

## ملخص جملة واحدة
تتيح الكلمة المحجوبة "abstract" في سكالا تعريف فئات ودوال غير مكتملة تحتاج إلى تنفيذ في الفئات الفرعية.
