# Scalaの「yield」: コレクションの変換と生成

## 概要
Scalaの「yield」は、コレクションを変換し、新しいコレクションを生成するための強力な構文です。この機能は、forループ内で使用され、各要素に対して操作を実行し、その結果を新しいコレクションとして返します。

## ドキュメンテーション
### 目的
「yield」は、コレクションの各要素に対して処理を行い、その結果を新しいコレクションとして得るために使用されます。これにより、ループの結果を簡潔に管理し、コードの可読性を向上させることができます。

### 使用法
「yield」は、forループの中で使用されます。基本的な構文は以下の通りです。

```scala
for (変数 <- コレクション) yield 表現
```

ここで、「変数」はコレクションの各要素を、 「コレクション」は操作対象のコレクションを、 「表現」は新しいコレクションに追加するための値を表します。

### 詳細
- 「yield」は、ArrayやListなどのコレクションに対して使用することができます。
- 生成される新しいコレクションは、元のコレクションと同じ型であるため、型安全です。
- フィルタリングや条件付きのロジックを組み込むことも可能です。

## 例
以下は、「yield」を用いた基本的な使用例です。

### 例1: 数値の二乗を生成
```scala
val numbers = List(1, 2, 3, 4, 5)
val squares = for (n <- numbers) yield n * n
println(squares) // 出力: List(1, 4, 9, 16, 25)
```

### 例2: 条件付き変換
```scala
val numbers = List(1, 2, 3, 4, 5)
val evenSquares = for (n <- numbers if n % 2 == 0) yield n * n
println(evenSquares) // 出力: List(4, 16)
```

### 例3: 文字列の大文字変換
```scala
val words = List("scala", "is", "fun")
val upperWords = for (word <- words) yield word.toUpperCase
println(upperWords) // 出力: List(SCALA, IS, FUN)
```

## 説明
「yield」を使用する際の一般的な落とし穴や注意点は以下の通りです。

- **ネスト**: 「yield」をネストさせることも可能ですが、可読性が低下するため、コードの意図が不明瞭になることがあります。
- **パフォーマンス**: 大きなコレクションに対して「yield」を使用すると、メモリ使用量が増加する可能性があります。必要に応じて、コレクションの操作を最適化することが重要です。
- **型の整合性**: ループ内で異なる型の値を生成すると、コンパイルエラーが発生します。常に同じ型の値を返すことを確認してください。

## 一文の要約
Scalaの「yield」は、コレクションの変換を簡潔に行い、新しいコレクションを生成するための構文です。
