# Scala의 extends 키워드: 상속과 다형성 이해하기

## 개요
Scala에서 `extends` 키워드는 클래스와 트레이트(특성)의 상속 관계를 정의하는 데 사용됩니다. 이를 통해 코드의 재사용성을 높이고, 상위 클래스의 메서드와 속성을 자식 클래스에서 쉽게 사용할 수 있도록 합니다.

## 문서화

### 목적
`extends` 키워드는 Scala의 객체 지향 프로그래밍에서 상속을 구현하는 데 필수적인 요소입니다. 객체 지향 프로그래밍의 핵심 개념인 상속을 사용하여 새로운 클래스를 기존 클래스의 특성을 기반으로 생성할 수 있습니다. 이로 인해 코드의 중복을 줄이고, 시스템의 유지 보수를 용이하게 합니다.

### 사용법
`extends` 키워드는 클래스를 정의할 때, 상속할 부모 클래스 또는 트레이트를 지정하는 데 사용됩니다. 기본 문법은 다음과 같습니다:

```scala
class 자식클래스명 extends 부모클래스명 {
  // 자식 클래스의 추가적인 속성 및 메서드
}
```

또한, 여러 트레이트를 상속받을 때는 `with` 키워드를 사용하여 연쇄적으로 정의할 수 있습니다:

```scala
class 자식클래스명 extends 부모클래스명 with 트레이트명 {
  // 자식 클래스의 추가적인 속성 및 메서드
}
```

### 세부사항
- **단일 상속**: Scala에서는 클래스가 다른 클래스 하나만 상속할 수 있지만, 여러 트레이트를 동시에 상속받을 수 있습니다.
- **트레이트**: 트레이트는 여러 클래스에서 공유할 수 있는 메서드와 속성을 정의할 수 있는 특수한 형태의 클래스입니다. 트레이트는 다중 상속의 기능을 제공합니다.
- **오버라이딩**: 상속된 메서드를 자식 클래스에서 재정의할 수 있으며, 이를 통해 다형성을 구현할 수 있습니다.

## 예제

### 기본 사용 예
```scala
// 부모 클래스 정의
class 동물 {
  def 소리(): String = "소리를 낸다"
}

// 자식 클래스 정의
class 개 extends 동물 {
  override def 소리(): String = "멍멍"
}

// 사용 예
val 내개 = new 개()
println(내개.소리())  // 출력: 멍멍
```

### 트레이트 사용 예
```scala
// 트레이트 정의
trait 수영 {
  def 수영하기(): String = "수영을 한다"
}

// 부모 클래스
class 동물 {
  def 소리(): String = "소리를 낸다"
}

// 자식 클래스가 트레이트와 부모 클래스를 동시에 상속
class 물개 extends 동물 with 수영 {
  override def 소리(): String = "왈왈"
}

// 사용 예
val 내물개 = new 물개()
println(내물개.소리())      // 출력: 왈왈
println(내물개.수영하기())  // 출력: 수영을 한다
```

## 설명
- **상속의 한계**: Scala는 단일 클래스 상속만 허용하므로, 부모 클래스가 여러 개일 경우 트레이트를 활용해야 합니다.
- **구조적 타입**: Scala는 클래스 대신 구조적 타입을 사용할 수 있는 기능을 제공하여, 더 유연한 코드 작성을 가능하게 합니다.
- **메서드 오버라이딩**: 부모 클래스의 메서드를 오버라이드할 때는 `override` 키워드를 사용해야 하며, 이를 통해 자식 클래스에서 부모 클래스의 기능을 변경할 수 있습니다.

## 한 줄 요약
Scala에서 `extends` 키워드는 클래스와 트레이트 간의 상속 관계를 정의하여 코드의 재사용성을 높이는 중요한 키워드입니다.
