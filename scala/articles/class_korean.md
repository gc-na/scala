# Scala의 클래스(Class): 객체 지향 프로그래밍의 기초

## 개요
Scala에서 클래스는 객체 지향 프로그래밍의 핵심 개념으로, 데이터와 그 데이터에 대한 작업을 캡슐화하는 데 사용됩니다. 클래스는 객체를 생성하기 위한 청사진 역할을 하며, 재사용 가능한 코드 구조를 제공합니다.

## 문서화
클래스는 Scala의 기본적인 빌딩 블록으로, 속성(필드)과 메서드를 포함하여 관련된 데이터를 그룹화합니다. 클래스는 다음과 같은 주요 요소를 포함합니다:

- **생성자(Constructor)**: 클래스 인스턴스를 생성할 때 호출되며, 초기화 작업을 수행합니다.
- **속성(Properties)**: 클래스의 상태를 나타내는 변수입니다.
- **메서드(Methods)**: 클래스의 기능을 정의하는 함수입니다.

클래스는 다음과 같이 정의할 수 있습니다:

```scala
class 클래스명(매개변수: 타입) {
  // 속성
  var 속성명: 타입 = 초기값

  // 메서드
  def 메서드명(매개변수: 타입): 반환타입 = {
    // 메서드 본문
  }
}
```

클래스는 기본적으로 `public` 접근 제한자를 가지며, 필요에 따라 `private`, `protected`와 같은 다른 접근 제한자를 사용할 수 있습니다.

## 예제
간단한 클래스 정의와 객체 생성 예제입니다:

```scala
// 클래스 정의
class Person(val name: String, var age: Int) {
  def greet(): String = s"안녕하세요, 제 이름은 $name이고 나이는 $age세입니다."
}

// 객체 생성
val person1 = new Person("홍길동", 30)
println(person1.greet()) // 출력: 안녕하세요, 제 이름은 홍길동이고 나이는 30세입니다.
```

이 예제에서 `Person` 클래스는 이름과 나이를 속성으로 가지며, `greet` 메서드를 통해 인사말을 생성합니다.

## 설명
클래스를 사용할 때 주의해야 할 몇 가지 사항은 다음과 같습니다:

- **초기화 오류**: 생성자에서 필드를 초기화하지 않으면 컴파일 오류가 발생합니다.
- **불변성**: `val`로 선언된 속성은 불변이며, 나중에 값을 변경할 수 없습니다. 필요에 따라 `var`를 사용하여 가변성을 부여할 수 있습니다.
- **상속**: Scala는 다중 상속을 지원하지 않지만, 트레이트(trait)를 사용하여 비슷한 기능을 구현할 수 있습니다.

클래스의 기능을 이해하고 잘 활용하면, 코드의 재사용성과 유지보수성을 높일 수 있습니다.

## 한 줄 요약
Scala의 클래스는 객체 지향 프로그래밍을 위한 데이터와 메서드를 캡슐화하는 구조체입니다.
