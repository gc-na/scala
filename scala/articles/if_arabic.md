# استخدام جملة "if" في لغة سكالا: الدليل الشامل

## ملخص
تعتبر جملة "if" في لغة سكالا واحدة من أهم أدوات التحكم في التدفق، حيث تتيح للمطورين اتخاذ قرارات شرطية في كود البرنامج. من خلال استخدامها، يمكن تنفيذ كود معين بناءً على تحقق شرط معين.

## الوثائق
تستخدم جملة "if" في سكالا لتقييم تعبير منطقي. إذا كان التعبير صحيحًا (true)، يتم تنفيذ الكود داخل كتلة "if". إذا كان التعبير خاطئًا (false)، يمكن استخدام كتلة "else" لتنفيذ كود بديل.

### الصياغة الأساسية:
```scala
if (شرط) {
  // الكود الذي سيتم تنفيذه إذا كان الشرط صحيحًا
} else {
  // الكود الذي سيتم تنفيذه إذا كان الشرط خاطئًا
}
```

### الاستخدام:
- **شرط إذا**: يتم استخدام "if" لتقييم شرط معين.
- **شرط بديل**: يمكن استخدام "else" لتحديد منطق بديل في حالة عدم تحقق الشرط.
- **شرط إضافي**: يمكن استخدام "else if" لتقييم شروط إضافية.

## أمثلة
### مثال 1: استخدام جملة "if" الأساسية
```scala
val a = 10
val b = 20
if (a < b) {
  println("a أصغر من b")
} else {
  println("a ليس أصغر من b")
}
```

### مثال 2: استخدام "else if"
```scala
val number = 0
if (number > 0) {
  println("العدد موجب")
} else if (number < 0) {
  println("العدد سالب")
} else {
  println("العدد صفر")
}
```

### مثال 3: تعبير "if" كقيمة
```scala
val max = if (a > b) a else b
println(s"القيمة الأكبر هي: $max")
```

## الشرح
### الأخطاء الشائعة:
- **نسيان الأقواس**: يجب استخدام الأقواس حول الشرط في جملة "if".
- **عدم استخدام "else" عند الحاجة**: قد يؤدي عدم استخدام "else" إلى عدم تنفيذ أي كود في حالات معينة.
- **استخدام "if" كجملة بدون كتلة**: في سكالا، يمكن استخدام "if" بصفة تعبير، ولكن يجب الحذر عند استخدامه كجملة فقط.

### ملاحظات إضافية:
- يمكن استخدام جملة "if" في أي مكان يمكن أن تتواجد فيه تعبيرات، وهذا يشمل داخل المتغيرات أو كجزء من تعبير أكبر.
- سكالا تدعم التعبيرات الشرطية المدمجة، مما يعني أنه يمكن استخدام "if" في تعيين قيم المتغيرات.

## ملخص من سطر واحد
تعتبر جملة "if" في سكالا أداة قوية للتحكم في تدفق البرنامج من خلال تقييم الشروط وتنفيذ كود محدد بناءً على ذلك.
