# Scala 中的 "if" 條件語句使用指南

## 概述
在 Scala 中，`if` 條件語句是一種基本的控制結構，用於根據布林條件的真偽來執行不同的代碼塊。這使得程式能夠根據運行時的狀態做出決策。

## 文檔
### 目的
`if` 語句的主要目的是提供一種方式來決定哪些代碼應該被執行，根據特定條件來控制程式的流向。

### 使用
`if` 語句的基本語法如下：
```scala
if (條件) {
  // 當條件為 true 時執行的代碼
} else {
  // 當條件為 false 時執行的代碼
}
```
在 Scala 中，`if` 語句不僅可以用於執行不同的代碼塊，還可以直接作為表達式返回值。這意味著你可以使用 `if` 來計算變量的值。

### 詳細說明
- **條件**: 條件必須是一個布林類型的表達式（即 `true` 或 `false`）。
- **else**: `else` 部分是可選的。若不提供，當條件為 false 時不會執行任何代碼。
- **作為表達式**: `if` 可以返回值，這使得它可以用於賦值，例如：
  ```scala
  val max = if (a > b) a else b
  ```

## 範例
### 基本用法
以下是一個簡單的 `if` 語句範例：
```scala
val number = 10

if (number > 0) {
  println("數字是正數")
} else {
  println("數字是非正數")
}
```

### 使用作為表達式
```scala
val a = 5
val b = 10

val max = if (a > b) a else b
println(max) // 輸出: 10
```

### 嵌套的 if 語句
```scala
val score = 85

if (score >= 90) {
  println("優秀")
} else if (score >= 75) {
  println("良好")
} else {
  println("及格")
}
```

## 解釋
### 常見陷阱
- **括號**: Scala 的 `if` 語句的條件部分必須使用小括號，但代碼塊則不需要大括號，當只有一行代碼時可以省略。
- **布林表達式**: 確保條件表達式的類型是布林型，否則會導致編譯錯誤。

### 注意事項
- `if` 語句可以在任何地方使用，包括函數和類內部。
- 使用 `if` 作為表達式時，必須確保所有可能的路徑都返回相同類型的值，否則會引發編譯錯誤。

## 一句話總結
在 Scala 中，`if` 條件語句是一種用於根據布林條件執行不同代碼塊的基本控制結構，並且可作為表達式返回值。
