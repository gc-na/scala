# Scala의 "else" 구문: 조건문에서의 활용

## 개요
Scala의 "else" 구문은 조건문에서 사용되어 특정 조건이 충족되지 않을 경우 대체 실행 경로를 정의하는 데 사용됩니다. 이를 통해 코드의 흐름을 제어하고 다양한 조건에 따른 처리를 가능하게 합니다.

## 문서화
"else"는 Scala에서 `if` 조건문과 함께 사용되며, 주어진 조건이 `false`일 때 실행할 코드를 지정합니다. 기본적인 구문은 다음과 같습니다:

```scala
if (조건) {
  // 조건이 true일 때 실행할 코드
} else {
  // 조건이 false일 때 실행할 코드
}
```

### 용도
- 조건에 따라 서로 다른 코드 블록을 실행하기 위해 사용됩니다.
- 복잡한 논리를 단순화하여 가독성을 높이는 데 기여합니다.

### 세부사항
- `else`는 `if`문 다음에 사용되어야 하며, 선택적으로 `else if` 구문을 추가하여 여러 조건을 처리할 수도 있습니다.
- 중괄호 `{}`는 여러 줄의 코드를 포함할 때 필요하며, 단일 표현식인 경우 생략할 수 있습니다. 

## 예제
### 기본 사용 예
```scala
val number = 5

if (number > 0) {
  println("양수입니다.")
} else {
  println("양수가 아닙니다.")
}
```

### `else if` 구문 사용 예
```scala
val score = 85

if (score >= 90) {
  println("A")
} else if (score >= 80) {
  println("B")
} else if (score >= 70) {
  println("C")
} else {
  println("D")
}
```

## 설명
"else" 구문을 사용할 때 몇 가지 주의해야 할 점이 있습니다:

- **중첩된 조건문**: 여러 조건문이 중첩될 경우 가독성이 떨어질 수 있으므로, 필요한 경우 별도의 메서드로 분리하는 것이 좋습니다.
- **조건문 간소화**: 복잡한 조건식은 가독성을 높이기 위해 변수에 저장해 사용하는 것이 바람직합니다.
- **코드 블록**: `else`와 함께 사용하는 코드 블록이 비어있을 수 있으므로, 의도적으로 아무 작업도 하지 않겠다는 것을 명확히 하기 위해 `()`를 사용할 수 있습니다.

## 한 줄 요약
Scala의 "else" 구문은 조건이 충족되지 않을 때 실행할 대체 코드를 정의하여 프로그램의 흐름을 제어하는 데 사용됩니다.
