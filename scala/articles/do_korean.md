# Scala의 do: 사용법과 예제

## 개요
Scala에서 `do`는 반복문을 구성하는 데 사용되는 키워드로, 블록 내의 코드를 최소한 한 번은 실행한 후 조건을 검사하여 반복 여부를 결정합니다. `do-while` 루프의 일부분으로 사용되며, 조건이 참인 동안 코드 블록이 반복 실행됩니다.

## 문서화
### 목적
`do` 키워드는 코드 블록을 반복 실행할 때 유용합니다. 최소한 한 번의 실행을 보장하고, 반복의 조건 검사 후에 코드 블록이 실행되도록 합니다.

### 사용법
`do`는 `do-while` 문과 함께 사용됩니다. 기본 구문은 다음과 같습니다:

```scala
do {
  // 실행할 코드 블록
} while (조건)
```

이 구조에서 코드 블록은 조건이 참인 동안 반복 실행됩니다. 조건은 루프가 끝날 때 검사되며, 조건이 거짓이 되면 루프가 종료됩니다.

### 세부사항
- `do` 블록 내의 코드는 반드시 한 번 실행됩니다.
- 조건식은 `while` 다음에 위치하며, 불리언 값을 반환해야 합니다.
- `do-while` 루프는 주로 사용자 입력이나 외부 조건에 따라 반복해야 할 때 유용합니다.

## 예제
### 기본 사용 예제
```scala
var i = 0
do {
  println(s"현재 i의 값은: $i")
  i += 1
} while (i < 5)
```
위의 코드는 `i`가 5보다 작을 때까지 `i`의 값을 출력하고 증가시킵니다. 이 예제의 출력은 0부터 4까지의 값입니다.

### 사용자 입력을 통한 반복
```scala
import scala.io.StdIn

var input: String = ""
do {
  println("종료하려면 'exit'를 입력하세요:")
  input = StdIn.readLine()
  println(s"입력된 값: $input")
} while (input != "exit")
```
위의 예제는 사용자가 'exit'를 입력할 때까지 계속해서 입력을 받습니다.

## 설명
### 일반적인 함정 및 주의사항
- `do` 루프에서 조건이 항상 참인 경우, 무한 루프에 빠질 수 있습니다. 따라서 조건을 항상 올바르게 설정해야 합니다.
- `do-while` 문은 조건 검사를 블록 실행 후에 수행하므로, 조건에 따라 루프가 실행되지 않을 수 있는 다른 반복문(예: `while`)과 혼동하지 않도록 주의해야 합니다.
  
## 한 줄 요약
Scala의 `do` 키워드는 최소한 한 번 코드 블록을 실행하고, 조건에 따라 반복하는 `do-while` 루프의 중요한 구성 요소입니다.
