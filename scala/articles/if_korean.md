# Scala의 "if" 문: 조건문 사용법과 예제

## 개요
Scala의 "if" 문은 조건에 따라 코드 블록을 실행하는 데 사용되는 제어 구조입니다. 이는 프로그램의 흐름을 제어하고, 복잡한 조건을 기반으로 다양한 경로를 선택할 수 있게 해줍니다.

## 문서화
### 목적
"if" 문은 특정 조건이 참(true)일 때와 거짓(false)일 때 각각 다른 코드를 실행할 수 있도록 설계되었습니다. 이를 통해 프로그램의 로직을 보다 유연하게 구성할 수 있습니다.

### 사용법
Scala에서 "if" 문은 다음과 같은 기본 형식을 가집니다:

```scala
if (조건) {
  // 조건이 참일 때 실행되는 코드
} else {
  // 조건이 거짓일 때 실행되는 코드 (선택적)
}
```

또한, 여러 조건을 처리하기 위해 `else if`를 사용할 수 있습니다:

```scala
if (조건1) {
  // 조건1이 참일 때 실행되는 코드
} else if (조건2) {
  // 조건2가 참일 때 실행되는 코드
} else {
  // 두 조건 모두 거짓일 때 실행되는 코드
}
```

### 세부사항
- **부울 표현식**: "if" 문은 부울 표현식을 사용하여 조건을 평가합니다.
- **단일 표현식**: Scala에서는 "if" 문이 단일 표현식으로도 사용될 수 있습니다. 즉, "if" 문 자체가 값을 반환할 수 있습니다.
  
```scala
val result = if (조건) {
  // 조건이 참일 때의 값
} else {
  // 조건이 거짓일 때의 값
}
```

## 예제
### 기본 사용 예
```scala
val x = 10
if (x > 5) {
  println("x는 5보다 큽니다.")
} else {
  println("x는 5보다 작거나 같습니다.")
}
```

### 여러 조건 처리
```scala
val y = 15
if (y < 10) {
  println("y는 10보다 작습니다.")
} else if (y < 20) {
  println("y는 10 이상 20 미만입니다.")
} else {
  println("y는 20 이상입니다.")
}
```

## 설명
- **중첩된 if 문**: "if" 문은 서로 중첩할 수 있지만, 지나치게 중첩하면 코드가 복잡해지고 가독성이 떨어질 수 있습니다. 따라서 가급적 간결한 구조를 유지하는 것이 좋습니다.
- **조건문과 단축 평가**: Scala의 "if" 문은 단축 평가(short-circuit evaluation)를 지원하지 않기 때문에, 모든 조건이 평가됩니다.
- **스칼라의 타입 추론**: "if" 문을 사용할 때, 반환되는 값의 타입은 두 코드 블록의 반환 타입에 따라 결정되며, 두 블록의 타입이 일치해야 합니다.

## 한 줄 요약
Scala의 "if" 문은 조건에 따라 코드의 실행 경로를 결정하는 강력한 제어 구조입니다.
