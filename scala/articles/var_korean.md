# Scala의 var: 변수 선언과 사용법

## 개요
Scala에서 `var`는 변경 가능한 변수를 선언하는 데 사용됩니다. 이는 프로그래밍에서 변동성이 필요한 데이터 모델링에 유용합니다.

## 문서화
`var` 키워드는 Scala에서 mutable(변경 가능한) 변수를 생성하는 데 사용됩니다. 기본적으로 `var`로 선언된 변수는 나중에 값을 변경할 수 있으며, 이는 프로그램의 상태를 동적으로 업데이트할 수 있게 해줍니다. `var`는 다음과 같은 형식으로 사용됩니다:

```scala
var 변수이름: 데이터타입 = 초기값
```

변수의 데이터 타입은 명시적으로 정의할 수도 있고, 컴파일러가 타입을 유추하도록 할 수도 있습니다. 예를 들어, 다음과 같이 사용할 수 있습니다:

```scala
var x: Int = 10 // 명시적 타입
var y = 20     // 타입 유추
```

이러한 방식으로 선언된 변수는 이후에 값이 변경될 수 있습니다:

```scala
x = 15
y += 5  // y는 이제 25가 됩니다.
```

## 예제
변수 `var`의 기본 사용 예시는 다음과 같습니다:

```scala
// 변수 선언
var age: Int = 30

// 변수 값 변경
age = 31

// 변수 출력
println(age) // 출력: 31
```

또한, `var`를 사용하여 배열이나 컬렉션과 같은 복합 데이터 구조에서도 값을 수정할 수 있습니다:

```scala
var numbers: Array[Int] = Array(1, 2, 3)
numbers(0) = 10  // 첫 번째 요소 변경
println(numbers.mkString(", ")) // 출력: 10, 2, 3
```

## 설명
`var`를 사용할 때 주의해야 할 점은 변수의 변경 가능성입니다. 프로그램이 복잡해질수록 상태의 변화를 추적하기 어려울 수 있으며, 이는 버그의 원인이 될 수 있습니다. 따라서, 가능하다면 변경 불가능한 변수(`val`)를 사용하는 것이 좋습니다.

또한, `var`로 선언된 변수를 사용하면 코드의 가독성이 떨어질 수 있으며, 함수형 프로그래밍 패러다임에 맞지 않을 수 있습니다. 함수형 프로그래밍에서는 부수 효과를 최소화하려 하므로, 변경 가능한 상태를 피하는 것이 일반적입니다.

## 한 줄 요약
Scala의 `var`은 변경 가능한 변수를 선언할 수 있는 키워드로, 프로그램의 동적 상태 관리에 유용하다.
