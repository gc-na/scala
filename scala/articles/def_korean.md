# Scala의 def: 함수 정의의 모든 것

## 개요
Scala에서 `def`는 함수를 정의하는 데 사용되는 키워드로, 프로그래밍에서 코드의 재사용성과 가독성을 높이는 중요한 요소입니다. 이 키워드는 함수의 이름, 매개변수, 반환 타입, 그리고 함수의 본체를 명시하는 데 사용됩니다.

## 문서화
`def` 키워드는 Scala에서 함수를 정의할 때 사용됩니다. 함수를 정의하는 기본 구문은 다음과 같습니다:

```scala
def functionName(parameter1: Type1, parameter2: Type2): ReturnType = {
  // 함수의 본체
}
```

### 목적
- 코드의 재사용을 가능하게 하여 중복을 줄입니다.
- 프로그램의 구조를 명확하게 하여 가독성을 향상시킵니다.

### 사용법
1. **함수 이름**: 함수의 고유 이름을 지정합니다.
2. **매개변수**: 함수에 전달될 입력값을 정의합니다. 각 매개변수는 이름과 타입으로 구성됩니다.
3. **반환 타입**: 함수가 반환하는 값의 타입을 명시합니다.
4. **함수 본체**: 함수의 동작을 정의하는 코드 블록입니다.

## 예제
다음은 `def`를 사용한 기본적인 함수 정의의 예입니다:

```scala
// 두 정수를 더하는 함수
def add(x: Int, y: Int): Int = {
  x + y
}

// 함수 호출
val sum = add(5, 3) // sum은 8이 됩니다.
```

또 다른 예제는 문자열을 출력하는 함수입니다:

```scala
// 문자열을 출력하는 함수
def printMessage(message: String): Unit = {
  println(message)
}

// 함수 호출
printMessage("안녕하세요, Scala!") // "안녕하세요, Scala!"가 출력됩니다.
```

## 설명
### 일반적인 오류 및 주의사항
- **매개변수 타입 미지정**: Scala는 타입 추론을 지원하지만, 명시적으로 타입을 지정하지 않으면 혼란을 초래할 수 있습니다.
- **반환 타입 불일치**: 함수 본체에서 반환하는 값의 타입이 선언된 반환 타입과 일치해야 합니다.
- **Unit 타입**: 반환 타입이 `Unit`인 경우, 함수 본체에서 값을 반환하지 않아도 됩니다. 그러나 명시적인 반환이 필요하지 않음을 주의해야 합니다.

### 추가 메모
- Scala에서는 익명 함수(람다)를 통해 `def` 없이도 함수를 정의할 수 있습니다.
- 함수는 다른 함수의 인자로 전달되거나 반환값으로 사용될 수 있어, 고차 함수 개념을 쉽게 구현할 수 있습니다.

## 한 줄 요약
Scala의 `def` 키워드는 함수 정의에 사용되며, 코드의 재사용성과 가독성을 향상시킵니다.
