# استخدام جملة "for" في لغة سكالا: دليلك الشامل

## ملخص
تعتبر جملة "for" في سكالا من الأدوات القوية التي تُستخدم للتكرار على المجموعات أو لإنشاء تعبيرات مختصرة، مما يسهل التعامل مع البيانات بطريقة فعالة وواضحة.

## الوثائق
تتيح لك جملة "for" في سكالا تنفيذ تكرار على عناصر المجموعات مثل القوائم، والمصفوفات، والمجموعات، وغيرها. يمكنك استخدامها لكتابة كود أكثر وضوحًا وقابلية للصيانة. يأتي استخدام "for" في شكلين رئيسيين: التجميع البسيط، والتجميع مع الشروط.

### الاستخدام
تستخدم جملة "for" بالشكل التالي:

```scala
for (element <- collection) {
  // تنفيذ الكود
}
```

يمكن أيضًا استخدام "for" مع الشروط:

```scala
for (element <- collection if condition) {
  // تنفيذ الكود
}
```

### التفاصيل
تسمح لك جملة "for" أيضًا بالتعامل مع المجموعات المتداخلة (nested collections) عن طريق استخدام جمل متعددة، مما يوفر طريقة مرنة لإنشاء مجموعات جديدة أو تنفيذ عمليات معقدة على البيانات.

## أمثلة
### مثال 1: تكرار بسيط
```scala
val numbers = List(1, 2, 3, 4, 5)
for (n <- numbers) {
  println(n)
}
```
### مثال 2: استخدام الشرط
```scala
val numbers = List(1, 2, 3, 4, 5)
for (n <- numbers if n % 2 == 0) {
  println(n) // سيطبع الأعداد الزوجية فقط
}
```
### مثال 3: تكرار على مجموعة متداخلة
```scala
val matrix = List(List(1, 2), List(3, 4))
for {
  row <- matrix
  element <- row
} {
  println(element)
}
```

## الشرح
من الأمور الشائعة التي يجب الانتباه إليها عند استخدام جملة "for" هي أنه يمكن أن تكون هناك تأثيرات على الأداء في حالة تكرار المجموعات الكبيرة. بالإضافة إلى ذلك، يجب الحرص على استخدام الشروط بشكل صحيح لتفادي أي أخطاء منطقية.

## ملخص جملة واحدة
جملة "for" في سكالا هي أداة قوية للتكرار على المجموعات وتسهيل كتابة الكود بطريقة واضحة وفعالة.
