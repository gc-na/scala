# Scala 中的 "for" 循環：用法與示例

## 簡介
在 Scala 程式語言中，`for` 循環是一個強大的控制結構，用於遍歷集合和進行重複操作。它的語法簡潔且靈活，適合用於各種情況。

## 文檔
`for` 循環的主要目的是讓開發者可以方便地遍歷集合或執行特定的操作。Scala 提供了多種 `for` 循環的變體，包括普通的 `for` 循環以及用於生成新集合的 `for` 表達式。

### 基本用法
`for` 循環的基本語法如下：

```scala
for (element <- collection) {
  // 執行操作
}
```

在這裡，`element` 是集合中的每一個元素，`collection` 是要遍歷的集合。

#### `for` 表達式
除了基本的 `for` 循環，Scala 還支持 `for` 表達式，這種方式可以生成新的集合。例如：

```scala
val squares = for (i <- 1 to 10) yield i * i
```

這將生成一個包含從 1 到 10 的平方數的集合。

## 示例
以下是一些 `for` 循環的基本示例：

### 示例 1：基本遍歷
```scala
val fruits = List("蘋果", "香蕉", "橙")
for (fruit <- fruits) {
  println(fruit)
}
```
這段代碼將遍歷並打印每一個水果名稱。

### 示例 2：使用 `for` 表達式
```scala
val numbers = List(1, 2, 3, 4, 5)
val doubled = for (n <- numbers) yield n * 2
println(doubled) // 輸出: List(2, 4, 6, 8, 10)
```
這段代碼將每一個數字乘以 2 並生成一個新集合。

### 示例 3：篩選條件
```scala
val evens = for (i <- 1 to 10 if i % 2 == 0) yield i
println(evens) // 輸出: Range(2, 4, 6, 8, 10)
```
這段代碼篩選出從 1 到 10 的偶數。

## 解釋
在使用 `for` 循環時，開發者常見的陷阱包括：

- **範圍邊界**：在使用範圍 (`1 to 10`) 時，要注意是包含結尾的數字，這可能與其他語言的用法不同。
- **可空集合**：遍歷一個可能為空的集合時，應確保不會導致空指針異常。
- **多重生成器**：使用多個生成器時，可能會導致性能問題，特別是在處理大型集合時。

## 總結
`for` 循環是一個靈活且強大的工具，適用於遍歷和操作集合，是 Scala 語言中不可或缺的特性之一。
