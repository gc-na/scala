# استخدام عبارة "yield" في لغة سكالا

## ملخص
عبارة "yield" في سكالا تُستخدم لتحويل المجموعات أو الحلقات إلى تسلسلات جديدة عبر إنتاج عناصر جديدة بناءً على عناصر المجموعة الأصلية. تُعتبر "yield" جزءًا أساسيًا من التعبيرات التكرارية وتُسهل كتابة الشيفرة بشكل أكثر وضوحًا وفعالية.

## الوثائق
تتيح عبارة "yield" للمطورين إمكانية إنشاء مجموعات جديدة من خلال تطبيق عملية على كل عنصر في مجموعة موجودة. تُستخدم عادةً داخل تعبيرات `for`، حيث يمكنها تحويل كل عنصر أو مجموعة عناصر إلى عنصر أو مجموعة عناصر جديدة.

### الغرض
الغرض من "yield" هو تسهيل عملية تحويل البيانات بطريقة سلسة وواضحة. بدلاً من استخدام حلقات تقليدية مع متغيرات مؤقتة، يمكن استخدام "yield" لإنشاء مجموعة جديدة مباشرةً.

### الاستخدام
يمكن استخدام "yield" في تعبيرات `for` كما يلي:

```scala
for (item <- collection) yield expression
```

حيث يتم استبدال `collection` بالمجموعة الأصلية و`expression` بالتعبير الذي يُنتج العناصر الجديدة.

### التفاصيل
- يمكن استخدام "yield" مع أي نوع من المجموعات (مثل: `List`, `Array`, `Set`).
- تُرجع "yield" مجموعة جديدة، مما يعني أن المجموعة الأصلية تظل دون تغيير.
- يمكن استخدام "yield" لإجراء عمليات معقدة على العناصر، مثل تصفية البيانات أو تحويلها.

## أمثلة
### مثال 1: استخدام "yield" مع قائمة
```scala
val numbers = List(1, 2, 3, 4, 5)
val doubled = for (n <- numbers) yield n * 2
println(doubled) // Output: List(2, 4, 6, 8, 10)
```

### مثال 2: تصفية العناصر باستخدام "yield"
```scala
val numbers = List(1, 2, 3, 4, 5)
val evenNumbers = for (n <- numbers if n % 2 == 0) yield n
println(evenNumbers) // Output: List(2, 4)
```

## الشرح
### الأخطاء الشائعة
- **عدم استخدام "yield" داخل تعبير `for`**: حيث يجب أن تُستخدم "yield" داخل تعبير `for` لتحويل العناصر.
- **نسيان استخدام المجموعات**: يجب أن تكون "yield" مرتبطة بمجموعات صحيحة مثل `List` أو `Array`.

### ملاحظات إضافية
- "yield" تعزز من قابلية قراءة الشيفرة، مما يجعل من السهل فهم عمليات التحويل.
- يمكن دمج "yield" مع عمليات أخرى مثل `map` و`filter` للحصول على نتائج أكثر تعقيدًا.

## ملخص جملة واحدة
عبارة "yield" في سكالا تُستخدم لتحويل المجموعات عبر إنتاج عناصر جديدة بطريقة واضحة وسهلة القراءة.
