# Scala의 "for" 구문: 효율적인 반복 처리

## 개요
Scala에서 "for" 구문은 컬렉션이나 범위의 요소를 순회할 때 사용하는 강력한 반복문입니다. 이 구문은 가독성이 뛰어나고 함수형 프로그래밍 패러다임을 지원하여 다양한 방식으로 데이터를 처리할 수 있습니다.

## 문서화

### 목적
"For" 구문은 주어진 컬렉션의 요소를 반복적으로 처리할 수 있게 해줍니다. Scala에서는 "for" 구문을 사용하여 리스트, 배열, 맵 등 다양한 데이터 구조를 쉽게 순회하고 변환할 수 있습니다.

### 사용법
Scala의 "for" 구문은 다음과 같은 기본 구문을 가집니다:

```scala
for (변수 <- 컬렉션) {
  // 반복할 코드
}
```

여기서 `변수`는 컬렉션의 각 요소를 나타내며, `컬렉션`은 반복할 대상입니다. 또한, "for" 구문은 조건문과 함께 사용할 수 있어 더욱 세밀한 제어가 가능합니다.

### 세부사항
- **중첩된 for 구문**: 여러 개의 컬렉션을 중첩하여 반복할 수 있습니다.
- **조건문 추가**: `if` 구문을 통해 특정 조건을 만족하는 요소만 선택할 수 있습니다.
- **변환**: "for" 구문을 사용하여 새로운 컬렉션을 생성할 수 있습니다.

## 예제

### 기본 사용법
```scala
val numbers = List(1, 2, 3, 4, 5)
for (n <- numbers) {
  println(n)
}
```

### 조건문과 함께 사용하기
```scala
val numbers = List(1, 2, 3, 4, 5)
for (n <- numbers if n % 2 == 0) {
  println(n) // 짝수만 출력
}
```

### 중첩 사용 예
```scala
val matrix = Array(Array(1, 2), Array(3, 4))
for (row <- matrix; element <- row) {
  println(element)
}
```

### 변환하여 새로운 컬렉션 생성
```scala
val numbers = List(1, 2, 3, 4, 5)
val doubled = for (n <- numbers) yield n * 2
println(doubled) // List(2, 4, 6, 8, 10)
```

## 설명
"For" 구문을 사용할 때 주의해야 할 몇 가지 사항은 다음과 같습니다:
- **컬렉션의 빈 값**: 빈 컬렉션에 대해 "for" 구문을 사용할 경우 반복문 내부 코드가 실행되지 않습니다.
- **변수 범위**: 반복문 내에서 선언된 변수는 해당 반복문 내에서만 유효합니다.
- **가독성**: 복잡한 조건이나 중첩된 "for" 구문은 가독성을 저하시킬 수 있으므로, 적절한 주석이나 코드 분할이 필요합니다.

## 한 줄 요약
Scala의 "for" 구문은 컬렉션의 요소를 반복하여 처리할 수 있는 간결하고 효율적인 방법입니다.
