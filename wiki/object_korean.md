# Scala의 object: 싱글턴 객체의 이해

## 개요
Scala에서 `object`는 싱글턴 객체를 정의하는데 사용되는 키워드입니다. 이는 클래스의 단일 인스턴스를 생성하며, 주로 유틸리티 메소드나 상수, 애플리케이션의 진입점으로 사용됩니다.

## 문서화
Scala의 `object`는 다음과 같은 목적과 사용법을 가지고 있습니다:

### 목적
- **싱글턴 패턴**: `object`는 클래스의 단일 인스턴스를 보장하여 메모리 사용을 최적화합니다.
- **정적 메소드**: 클래스가 아닌 컨텍스트에서 메소드를 정의할 수 있어, 유틸리티 함수 등을 작성할 때 유용합니다.
- **명시적인 네임스페이스**: 관련된 메소드를 그룹화하여 코드의 가독성과 구조를 향상시킵니다.

### 사용법
`object`는 다음과 같은 형식으로 정의합니다:

```scala
object ObjectName {
  // 메소드 및 변수 정의
}
```

`object`는 클래스처럼 메소드를 가질 수 있으며, 이를 통해 기능을 구현할 수 있습니다. `object`는 또한 애플리케이션의 메인 진입점으로 사용될 수 있습니다.

## 예제
다음은 `object`의 기본 사용 예입니다:

```scala
object MathUtils {
  def add(x: Int, y: Int): Int = x + y
  def multiply(x: Int, y: Int): Int = x * y
}

object Main extends App {
  println(MathUtils.add(5, 10))      // 출력: 15
  println(MathUtils.multiply(5, 10))  // 출력: 50
}
```

위 예제에서 `MathUtils`는 두 개의 메소드를 포함하는 싱글턴 객체입니다. `Main` 객체는 애플리케이션의 시작 지점으로 사용됩니다.

## 설명
`object`를 사용할 때 주의해야 할 몇 가지 사항은 다음과 같습니다:

- **상태 유지**: `object`는 상태를 유지하지 않는 것이 좋습니다. 상태를 가진 경우, 여러 스레드에서 접근할 때 문제가 발생할 수 있습니다.
- **상속**: `object`는 클래스를 상속할 수 없지만, 다른 객체와 믹스인할 수 있습니다. 이는 유틸리티 메소드의 재사용성을 높이는 데 도움이 됩니다.
- **컴파일 타임**: `object`는 컴파일 타임에 초기화되며, 프로그램이 시작될 때 단 한 번만 생성됩니다.

## 한 줄 요약
Scala의 `object`는 싱글턴 객체를 정의하는 키워드로, 유틸리티 메소드와 애플리케이션의 진입점을 제공합니다.
