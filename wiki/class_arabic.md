# الفئة (Class) في لغة سكالا: كل ما تحتاج معرفته

## الملخص
الفئة (Class) هي أحد العناصر الأساسية في برمجة كائنات سكالا، حيث تُستخدم لإنشاء نماذج (Models) تمثل البيانات والسلوكيات المرتبطة بها. توفر الفئات طريقة فعالة لتنظيم الكود وإعادة استخدامه.

## الوثائق
تعتبر الفئة في سكالا هي قالب أو نموذج يُستخدم لإنشاء كائنات (Objects). تحتوي الفئات على خصائص (Attributes) وسلوكيات (Methods) تعكس البيانات التي تمثلها. يمكنك تعريف الفئة باستخدام الكلمة المفتاحية `class`، وتستطيع أن تحتوي على معلمات للمُنشئ (Constructor) لتعريف كيفية إنشاء الكائنات منها.

### الاستخدام
تُستخدم الفئات لتجميع البيانات والوظائف ذات الصلة. يمكن أن تحتوي الفئة على:
- خصائص: تمثل بيانات أو صفات الكائن.
- دوال: تمثل سلوكيات الكائن.

### التفاصيل
يمكن أن تحتوي الفئات على:
- مُنشئ (Constructor): يُستخدم لتهيئة الكائن عند إنشائه.
- وراثة (Inheritance): يمكن لفئة أن ترث خصائص ودوال من فئة أخرى.
- تعدد الأشكال (Polymorphism): يمكن استخدام دوال بنفس الاسم ولكن بطرق مختلفة.

## الأمثلة
### تعريف فئة بسيطة
```scala
class شخص(val الاسم: String, val العمر: Int) {
  def تقديم(): String = s"مرحبًا، أنا $الاسم، وعُمري $العمر سنة."
}

// إنشاء كائن من الفئة
val شخص1 = new شخص("علي", 25)
println(شخص1.تقديم()) // يطبع: مرحبًا، أنا علي، وعُمري 25 سنة.
```

### فئة مع مُنشئ افتراضي
```scala
class حيوان(val النوع: String) {
  def صرخ(): String = s"$النوع يصدر صوتًا!"
}

// إنشاء كائن من الفئة
val قطة = new حيوان("قطة")
println(قطة.صرخ()) // يطبع: قطة يصدر صوتًا!
```

## الشرح
- **الأخطاء الشائعة**: قد يواجه المبتدئون صعوبة في فهم كيفية استخدام المُنشئات أو الوراثة بشكل صحيح. من المهم التأكد من أن أسماء الخصائص والدوال متطابقة مع ما تم تعريفه في الفئة.
- **نقاط يجب الانتباه لها**: يمكن أن تؤدي استخدام الفئات بشكل غير صحيح إلى إشكاليات في الأداء أو صعوبة في صيانة الكود. يُفضل استخدام الفئات لتنظيم الكود بدلاً من استخدام هياكل بيانات بسيطة.

## ملخص جملة واحدة
الفئة في سكالا هي هيكل أساسي لإنشاء كائنات تمثل البيانات والسلوكيات، مما يسهل تنظيم وإدارة الكود.
