# Scala의 while 문: 반복문 사용법과 예제

## 개요
Scala의 `while` 문은 조건이 참인 동안 특정 블록의 코드를 반복 실행하는 제어 구조입니다. 이 문은 무한 루프나 조건에 따라 동적으로 반복해야 하는 상황에서 유용하게 사용됩니다.

## 문서화
`while` 문은 반복 실행을 위해 사용되는 기본적인 제어 구조입니다. `while` 문은 다음과 같은 형식으로 작성됩니다:

```scala
while (조건) {
  // 실행할 코드
}
```

### 목적
`while` 문의 주 목적은 특정 조건이 참인 동안 반복적으로 코드를 실행하는 것입니다. 이는 루프를 통해 데이터 처리를 반복하거나 사용자 입력을 기다리는 등 다양한 용도로 활용됩니다.

### 사용법
`while` 문은 조건을 평가한 후, 조건이 참인 경우에만 블록 내의 코드를 실행합니다. 조건이 거짓이 되면 루프가 종료됩니다. 

예를 들어:
```scala
var i = 0
while (i < 5) {
  println(i)
  i += 1
}
```
위 코드는 `i`가 5보다 작을 동안 `i`의 값을 출력하고, 매 반복마다 `i`를 1씩 증가시킵니다.

## 예제
1. 기본적인 `while` 문 사용 예제:
```scala
var count = 0
while (count < 3) {
  println("Count is: " + count)
  count += 1
}
```

2. 무한 루프와 종료 조건:
```scala
var input = ""
while (input != "exit") {
  input = scala.io.StdIn.readLine("Enter something (type 'exit' to quit): ")
  println("You entered: " + input)
}
```

## 설명
`while` 문을 사용할 때 주의해야 할 몇 가지 사항이 있습니다:

- **무한 루프**: 조건이 항상 참인 경우, `while` 문은 무한 루프에 빠질 수 있습니다. 이 경우 프로그램이 종료되지 않거나 예기치 않은 결과를 초래할 수 있습니다.
- **변수의 초기화**: 루프 내에서 사용되는 변수가 적절히 초기화되고, 루프의 종료 조건을 만족하도록 업데이트되어야 합니다. 그렇지 않으면 무한 루프가 발생할 수 있습니다.
- **성능**: `while` 문은 반복 횟수가 명확하지 않을 때 유용하지만, 반복 횟수가 정해져 있을 경우에는 `for` 문을 사용하는 것이 더 명확하고 성능이 좋을 수 있습니다.

## 한 줄 요약
Scala의 `while` 문은 주어진 조건이 참인 동안 코드를 반복 실행하는 제어 구조입니다.
