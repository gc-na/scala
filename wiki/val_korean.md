# Scala의 'val': 불변 변수 선언

## 개요
Scala에서 'val'은 불변 변수를 선언하는 데 사용되는 키워드입니다. 'val'로 선언된 변수는 한 번만 값을 할당할 수 있으며, 이후에는 값을 변경할 수 없습니다. 이는 함수형 프로그래밍의 원칙을 따르며, 코드의 안정성과 가독성을 높이는 데 기여합니다.

## 문서화
### 목적
'val'은 변수를 선언할 때 사용되며, 해당 변수에 할당된 값을 변경할 수 없도록 보장합니다. 이는 프로그램의 상태를 예측 가능하게 만들고, 불필요한 사이드 이펙트를 줄이는 데 도움을 줍니다.

### 사용법
'val'을 사용하여 변수를 선언할 때는 다음과 같은 구문을 사용합니다:

```scala
val variableName: Type = initialValue
```

여기서 `variableName`은 변수의 이름, `Type`은 변수의 데이터 타입, `initialValue`는 초기값을 나타냅니다.

### 세부사항
- 'val'로 선언된 변수는 재할당이 불가능하지만, 변수의 내부 상태는 변경될 수 있습니다. 예를 들어, 객체의 속성은 변경할 수 있습니다.
- Scala는 타입 추론 기능을 제공하므로, 타입을 명시적으로 지정하지 않아도 됩니다.
- 'val'은 보통 상수를 정의하거나 불변 컬렉션을 만들 때 사용됩니다.

## 예제
다음은 'val'을 사용한 기본적인 예입니다:

```scala
// 기본적인 val 변수 선언
val x: Int = 10
println(x) // 출력: 10

// 타입 추론을 사용하는 val 변수 선언
val name = "Scala"
println(name) // 출력: Scala

// 불변 리스트 선언
val numbers = List(1, 2, 3)
println(numbers) // 출력: List(1, 2, 3)

// 내부 상태 변경 가능
val person = new Person("John")
person.age = 30 // 객체의 속성은 변경 가능
```

## 설명
- **일관성 문제**: 'val'로 선언된 변수를 변경할 수 없으므로, 프로그래머는 초기값을 신중하게 설정해야 합니다. 초기값이 잘못되면 프로그램이 예상과 다르게 동작할 수 있습니다.
- **불변성과 성능**: 불변 객체는 쓰레드 안전성을 높이고, 여러 쓰레드에서 동시에 접근할 때 발생할 수 있는 문제를 피할 수 있습니다.
- **타입 명시**: 타입을 명시하지 않으면, 컴파일러가 타입을 추론합니다. 하지만 복잡한 타입의 경우, 명시적으로 설정하는 것이 좋습니다.

## 한 문장 요약
Scala의 'val'은 불변 변수를 선언하여 코드의 안정성과 예측 가능성을 높이는 데 기여하는 키워드입니다.
