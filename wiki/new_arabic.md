# الكلمة المفتاحية "new" في لغة سكالا: إنشاء الكائنات

## ملخص
تعتبر الكلمة المفتاحية "new" في لغة سكالا وسيلة لإنشاء كائنات جديدة من الفئات (Classes). تُستخدم "new" لإنشاء مثيلات جديدة من الكائنات، مما يساعد في تنظيم الكود وتسهيل البرمجة الكائنية.

## الوثائق
### الغرض
تُستخدم الكلمة المفتاحية "new" في سكالا لتخصيص الذاكرة لكائن جديد من فئة معينة. تُعتبر هذه العملية جزءًا أساسيًا من البرمجة الكائنية، حيث تُتيح للمطورين إنشاء كائنات تحمل بيانات وسلوكيات محددة.

### الاستخدام
تظهر الكلمة "new" في سكالا عند الحاجة لإنشاء كائن جديد. يتبعها اسم الفئة، ويمكن أيضًا تمرير المعاملات إلى المُنشئ.

#### الصيغة الأساسية
```scala
val الكائن = new اسم_الفئة(المعاملات)
```

### التفاصيل
- عند استخدام "new"، يتم استدعاء المُنشئ (Constructor) للفئة المحددة.
- يمكن أن تحتوي الفئات على مُنشئ افتراضي (default constructor) أو مُنشئات متعددة (overloaded constructors) لاستيعاب متطلبات مختلفة.
- عند إنشاء كائن جديد، يتم تخصيص الذاكرة له في الذاكرة.

## أمثلة
### مثال 1: إنشاء كائن من فئة بسيطة
```scala
class شخص(val اسم: String, val عمر: Int)

val شخص1 = new شخص("أحمد", 30)
println(s"${شخص1.اسم} هو في سن ${شخص1.عمر}")
```

### مثال 2: استخدام مُنشئ افتراضي
```scala
class سيارة(val ماركة: String) {
  def عرضماركة(): Unit = {
    println(s"ماركة السيارة هي: $ماركة")
  }
}

val سيارتي = new سيارة("تويوتا")
سيارتي.عرضماركة()
```

## الشرح
### الأخطاء الشائعة
- **نسيان استخدام "new"**: في بعض الحالات، قد ينسى المطورون استخدام الكلمة "new" عند إنشاء كائن، مما يؤدي إلى أخطاء في الكود.
- **التحويل بين أنواع الكائنات**: يجب توخي الحذر عند تحويل أنواع الكائنات، حيث يمكن أن يؤدي ذلك إلى استثناءات في وقت التشغيل إذا كان التحويل غير صحيح.

### ملاحظات إضافية
- في سكالا، إذا كان لديك مُنشئ افتراضي، يمكنك إنشاء كائن دون استخدام "new":
```scala
val شخص2 = شخص("علي", 25) // لا حاجة لـ "new"
```
- يمكن استخدام "new" مع الكائنات المجردة (case classes) بنفس الطريقة.

## ملخص الجملة
تُستخدم الكلمة المفتاحية "new" في لغة سكالا لإنشاء كائنات جديدة من الفئات، مما يسهل البرمجة الكائنية.
