# Scala 中的类（Class）详解

## 概述
在 Scala 中，类是面向对象编程的基本构建块。它用于创建对象，并定义对象的属性和方法。

## 文档
### 目的
类用于封装数据和行为，提供了一种组织代码的方式，使得程序更具可读性和可维护性。

### 使用
在 Scala 中，定义类的基本语法如下：

```scala
class ClassName {
  // 属性和方法定义
}
```

类可以包含构造函数、字段、方法和其他成员。Scala 支持主构造函数和辅助构造函数。

#### 示例
以下是一个简单的类定义示例：

```scala
class Person(val name: String, var age: Int) {
  def greet(): String = {
    s"你好，我是 $name，年龄 $age 岁。"
  }
}

// 创建对象
val person = new Person("小明", 20)
println(person.greet()) // 输出: 你好，我是 小明，年龄 20 岁。
```

在这个例子中，`Person` 类有两个参数 `name` 和 `age`，并且有一个方法 `greet()` 用于输出问候信息。

## 解释
### 常见陷阱
1. **默认参数**: Scala 允许在类的构造函数中使用默认参数，但在使用时需要确保参数类型与默认值匹配。
   
2. **不可变性**: 使用 `val` 定义的属性是不可变的，而 `var` 定义的属性是可变的。对于数据不需要更改的情况，建议使用 `val`。

3. **继承**: Scala 中的类可以继承其他类，但需要使用关键字 `extends`，并且要注意构造函数的调用顺序。

4. **伴生对象**: 类可以有伴生对象（`object`），用于定义静态方法和属性。伴生对象与类同名，并且可以访问类的私有成员。

### 附加说明
- 在 Scala 中，类可以实现接口（trait），这为多态提供了支持。
- 类的成员可以是 `private`、`protected` 或 `public`，以控制可见性。
- Scala 的类支持模式匹配和解构赋值，让数据处理更加灵活。

## 一句话总结
Scala 中的类是面向对象编程的核心，允许开发者定义数据结构和相关行为。
