# Scala에서의 "abstract": 추상 클래스와 메소드에 대한 완벽 가이드

## 개요
Scala에서 "abstract"는 추상 클래스와 추상 메소드를 정의하는 데 사용되는 키워드로, 객체 지향 프로그래밍의 기본 개념을 지원합니다. 이를 통해 코드의 재사용성과 유연성을 높일 수 있습니다.

## 문서화
"abstract" 키워드는 Scala에서 클래스나 메소드를 정의할 때 사용됩니다. 추상 클래스는 인스턴스를 생성할 수 없는 클래스이며, 하나 이상의 추상 메소드를 포함할 수 있습니다. 추상 메소드는 구현이 없고, 서브클래스에서 반드시 구현해야 하는 메소드입니다. 이러한 기능은 다형성을 제공하고, 공통적인 인터페이스를 정의하는 데 유용합니다.

### 목적
- 코드 재사용: 공통된 기능을 가진 클래스를 정의하고, 이를 상속받아 구현할 수 있습니다.
- 다형성: 다양한 서브클래스에서 동일한 메소드를 다르게 구현할 수 있습니다.

### 사용법
1. **추상 클래스 정의**: `abstract class` 키워드를 사용하여 클래스를 정의합니다.
2. **추상 메소드 정의**: `def` 키워드 뒤에 `abstract`를 사용하여 메소드를 정의합니다.

### 세부 사항
- 추상 클래스는 `new` 키워드를 사용하여 인스턴스를 생성할 수 없습니다.
- 서브클래스에서는 모든 추상 메소드를 구현해야 합니다.
- 추상 메소드는 일반 메소드와 동일하게 매개변수를 가질 수 있습니다.

## 예제
```scala
// 추상 클래스 정의
abstract class Animal {
  def sound(): String // 추상 메소드
}

// 서브클래스 정의
class Dog extends Animal {
  override def sound(): String = "Bark" // 메소드 구현
}

class Cat extends Animal {
  override def sound(): String = "Meow" // 메소드 구현
}

// 사용 예
val dog: Animal = new Dog()
val cat: Animal = new Cat()

println(dog.sound()) // 출력: Bark
println(cat.sound()) // 출력: Meow
```

## 설명
- **일반 클래스와의 차이**: 추상 클래스는 인스턴스를 생성할 수 없다는 점에서 일반 클래스와 다릅니다. 따라서, 추상 클래스는 주로 다른 클래스의 기반으로 사용됩니다.
- **추상 메소드의 구현**: 모든 서브클래스는 추상 메소드를 반드시 구현해야 하며, 이를 통해 공통 인터페이스를 제공하게 됩니다.
- **추상 클래스의 활용**: 추상 클래스는 전체 시스템의 아키텍처를 구성하는 데 도움을 주며, 상속을 통해 코드의 유연성을 높입니다.

## 한 줄 요약
Scala에서 "abstract"는 추상 클래스와 메소드를 정의하여 코드의 재사용성과 다형성을 지원하는 키워드입니다.
