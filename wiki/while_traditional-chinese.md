# Scala 的 "while" 迴圈：使用與範例詳解

## 簡介
在 Scala 編程語言中，`while` 迴圈是一種控制結構，用於在特定條件為真時重複執行一段程式碼。這種迴圈特別適合於在執行某些操作之前不確定執行次數的情況。

## 文件說明
`while` 迴圈的基本語法如下：

```scala
while (條件) {
  // 執行的程式碼
}
```

### 目的
`while` 迴圈的主要目的是在條件滿足時反覆執行一段程式碼。當條件變為假時，迴圈將停止執行。

### 使用方式
1. **條件判斷**：`while` 迴圈會在每次執行之前判斷給定的條件。如果條件為真，則執行迴圈內的程式碼；如果為假，則結束迴圈。
2. **無限迴圈**：要注意，如果不在迴圈內部更改使條件變為假的變數，可能會導致無限迴圈。
3. **可用於各種資料型別**：`while` 迴圈可以與任何可評估為布林值的表達式一起使用，例如數字比較、布林變數等。

### 詳細說明
`while` 迴圈的執行流程如下：
- 在進入迴圈之前，先評估條件。
- 如果條件為真，執行迴圈內的程式碼。
- 完成後，返回到條件評估步驟，重複以上過程，直到條件為假。

這種迴圈適合用於需要多次執行的情境，例如從用戶那裡獲取輸入或處理資料集。

## 範例
以下是一些使用 `while` 迴圈的基本範例：

### 範例 1：計數器
```scala
var count = 0
while (count < 5) {
  println("計數：" + count)
  count += 1
}
```

### 範例 2：用戶輸入
```scala
var input = ""
while (input != "exit") {
  println("請輸入內容（輸入 'exit' 結束）：")
  input = scala.io.StdIn.readLine()
}
```

## 解釋
### 常見陷阱
- **無限迴圈**：最常見的錯誤是未能在迴圈內適當更新條件，導致無限迴圈。確保在迴圈內有邏輯來改變條件。
- **條件邏輯**：使用複雜的條件時，需謹慎考量所有可能的情況，避免意外的結束條件。

### 附加注意事項
- `while` 迴圈可能不是執行效率最高的選擇，特別是對於大型資料集。根據情況，考慮使用其他集合操作或遞歸。
- 在 Scala 中，還可以使用 `do...while` 迴圈，這種迴圈至少會執行一次，即使條件最初為假。

## 一句總結
在 Scala 中，`while` 迴圈是一種有效的控制結構，允許在給定條件為真時重複執行程式碼。
