# Scalaの「if」文：条件分岐の基本

## 概要
Scalaの「if」文は、条件に基づいて異なるコードブロックを実行するための制御構文です。この機能により、プログラマーはプログラムの流れを動的に変更することができます。

## ドキュメンテーション
「if」文は、条件が真（true）である場合に特定の処理を実行し、偽（false）である場合には別の処理を実行するために使用されます。Scalaでは、「if」文を使用して、より複雑な条件分岐を実装することが可能です。

### 使用法
基本的な構文は以下の通りです：

```scala
if (条件) {
  // 条件が真の場合の処理
} else {
  // 条件が偽の場合の処理
}
```

### 詳細
- **条件**：Boolean型の値が求められます。条件が真である場合、最初のコードブロックが実行されます。
- **else節**：オプションで、条件が偽の場合の処理を定義します。
- **else if**：複数の条件を連続して評価するために「else if」を使用することができます。

## 例
以下は「if」文の基本的な使用例です：

```scala
val number = 10

if (number > 0) {
  println("正の数です")
} else {
  println("ゼロまたは負の数です")
}
```

複数の条件を評価する例：

```scala
val score = 85

if (score >= 90) {
  println("優秀")
} else if (score >= 75) {
  println("良好")
} else {
  println("努力が必要です")
}
```

## 説明
「if」文を使用する際の一般的な落とし穴と注意点：

- **条件がBooleanであること**：条件として使用する式は、Boolean型でなければなりません。例えば、整数や文字列を直接条件にすることはできません。
- **スコープ**：if文の中で定義された変数は、そのスコープ内でのみ有効です。外部からアクセスすることはできません。
- **return値**：Scalaでは、「if」文は値を返すことができます。条件に応じて異なる値を返したい場合、次のように記述できます：

```scala
val result = if (number > 0) "正" else "負またはゼロ"
```

## 一文要約
