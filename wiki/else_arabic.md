# استخدام "else" في لغة سكالا: دليل شامل

## ملخص
"else" هو عبارة شرطية تستخدم في لغة سكالا لتوفير مسار بديل لتنفيذ الكود عندما لا تتحقق شرطية معينة.

## الوثائق
### الغرض
تعتبر جملة "else" جزءًا من جمل التحكم في التدفق في سكالا، حيث يتم استخدامها لتحديد ما يجب القيام به إذا كانت الشرطية السابقة (مثل "if") غير صحيحة. 

### الاستخدام
تستخدم "else" بعد جملة "if" لتحديد كتلة من الكود سيتم تنفيذها إذا كانت الشرطية في "if" غير صحيحة. يمكن استخدام "else" بمفرده، أو مع "if" لإنشاء عبارات شرطية مركبة.

### التركيب
```scala
if (شرط) {
  // تنفيذ هذا الكود إذا كان الشرط صحيحًا
} else {
  // تنفيذ هذا الكود إذا كان الشرط غير صحيح
}
```

يمكن أيضًا استخدام "else if" لتحديد شروط إضافية:

```scala
if (شرط1) {
  // تنفيذ هذا الكود إذا كان شرط1 صحيحًا
} else if (شرط2) {
  // تنفيذ هذا الكود إذا كان شرط2 صحيحًا
} else {
  // تنفيذ هذا الكود إذا لم يكن أي من الشرطين صحيحًا
}
```

## أمثلة
### مثال 1: استخدام "else" البسيط
```scala
val عدد = 10

if (عدد > 5) {
  println("العدد أكبر من 5")
} else {
  println("العدد 5 أو أقل")
}
```

### مثال 2: استخدام "else if"
```scala
val درجة = 85

if (درجة >= 90) {
  println("ممتاز")
} else if (درجة >= 75) {
  println("جيد جدا")
} else {
  println("جيد")
}
```

## الشرح
### الأخطاء الشائعة
- **نسيان الأقواس**: قد تؤدي كتابة الشروط بدون أقواس إلى أخطاء في التنفيذ.
- **عدم استخدام "else"**: إذا كان هناك حاجة لتنفيذ كود بديل، يجب استخدام "else" بشكل صحيح.
- **عدم التحقق من جميع الشرطيات**: في حالة استخدام "else if"، يجب التأكد من تغطية جميع الاحتمالات لتجنب تنفيذ كود غير متوقع.

### ملاحظات إضافية
- يمكن أن تحتوي جملة "if" على تعبيرات معقدة، مما يزيد من قوة وسهولة استخدام "else".
- يمكن استخدام "else" مع أي نوع من أنواع البيانات أو التعبيرات، مما يجعلها أداة مرنة للغاية.

## ملخص جملة واحدة
تستخدم "else" في سكالا لتحديد كود بديل يتم تنفيذه عندما لا تتحقق الشرطيات المحددة في جملة "if".
