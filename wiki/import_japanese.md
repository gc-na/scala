# Scalaにおける「import」: モジュール間の依存関係を管理する方法

## 概要
Scalaの「import」文は、他のパッケージやオブジェクトからクラスやメソッドを利用するために使用されます。この機能により、コードの再利用性が高まり、構造化されたプログラミングが実現します。

## ドキュメンテーション
### 目的
「import」文は、Scalaプログラム内で外部のクラスやオブジェクトを参照可能にし、名前空間を管理するために必要です。これにより、異なるモジュール間で依存関係を明示的に定義できます。

### 使用法
Scalaでは、以下のように「import」文を使用します。

```scala
import パッケージ名.クラス名
```

また、すべてのクラスやメソッドをインポートする場合は、アスタリスク (`*`) を使用できます。

```scala
import パッケージ名._
```

### 詳細
- **パッケージのインポート**: 特定のパッケージ内のクラスをインポートすることで、名前を短縮できます。
- **オブジェクトのインポート**: オブジェクトやシングルトンのメソッドを呼び出す際にも利用します。
- **クラスのエイリアス**: インポート時に別名を付けることも可能です。これにより、名前の衝突を避けることができます。
  
```scala
import パッケージ名.クラス名 => 別名
```

## 例
以下は「import」を使用した基本的な例です。

```scala
// Mathオブジェクトの利用
import scala.math._

val result = sqrt(16) // resultは4.0になります
println(result)
```

```scala
// 複数のクラスをインポート
import scala.collection.mutable.{ListBuffer, Map}

val buffer = ListBuffer(1, 2, 3)
val map = Map(1 -> "one", 2 -> "two")
```

## 説明
- **一般的な落とし穴**: 同じ名前のクラスやメソッドが複数のパッケージに存在する場合、どのクラスが使われるかを明確にする必要があります。これを避けるために、エイリアスを使用することが推奨されます。
- **インポートのスコープ**: インポートは、その行より下のスコープでのみ有効です。したがって、大きなコードベースでは、インポート文を適切な位置に配置することが重要です。

## 一文要約
Scalaの「import」文は、他のパッケージやオブジェクトからクラスやメソッドを利用するための機能であり、コードの再利用性を向上させます。
