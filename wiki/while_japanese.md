# Scalaにおける「while」ループの使い方

## 概要
Scalaの「while」ループは、条件が真である限り、指定されたコードブロックを繰り返し実行する制御フロー構造です。プログラムの流れを制御し、反復処理を簡単に行うことができます。

## ドキュメント
「while」ループは、条件式がtrueの間、ループ内のコードを繰り返し実行します。基本的な構文は以下の通りです。

```scala
while (条件) {
  // 繰り返す処理
}
```

### 使用方法
1. **条件の指定**: 条件はboolean式であり、trueまたはfalseの値を持ちます。
2. **コードブロック**: 条件がtrueである限り、コードブロック内の処理が実行されます。

### 詳細
- 「while」ループは、初めに条件を評価します。条件がfalseに評価された場合、ループは一度も実行されない可能性があります。
- ループ内の処理が完了すると、再度条件が評価され、trueの場合は再びコードブロックが実行されます。

## 例
以下に「while」ループの基本的な使用例を示します。

```scala
var i = 0
while (i < 5) {
  println(s"現在の値: $i")
  i += 1
}
```

この例では、変数iが5未満の間、現在の値を出力し、iを1ずつ増加させます。

## 説明
- **無限ループ**: 条件が常にtrueである場合、無限ループが発生する可能性があります。適切に条件を設定し、ループの終端を意識することが重要です。
- **コードの可読性**: 「while」ループは単純な反復処理には適していますが、条件が複雑な場合は、他の構造（例えば「for」ループ）を使用する方が可読性が向上することがあります。
- **ループの中断**: ループを途中で終了したい場合は、`break`文を使用することができますが、Scalaの標準ライブラリにおいては、`break`を使用するためには`scala.util.control.Breaks`をインポートする必要があります。

## 一文要約
Scalaの「while」ループは、指定した条件が真である限り、コードブロックを繰り返し実行するための制御構造です。
