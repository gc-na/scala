# استخدام الكلمة المفتاحية "extends" في لغة البرمجة سكالا

## ملخص
تستخدم الكلمة المفتاحية "extends" في لغة البرمجة سكالا لتحديد وراثة الفئات (classes) والتعريف عن الفئات الأساسية (superclasses) التي يتم توسيعها. تُعتبر الوراثة جزءًا أساسيًا من البرمجة الكائنية (object-oriented programming) وتسمح بإعادة استخدام الكود والتوسع في الوظائف.

## الوثائق
### الغرض
تُستخدم الكلمة "extends" لإنشاء فئة جديدة تستند إلى فئة موجودة، مما يتيح لها الحصول على الخصائص والأساليب (methods) من الفئة الأساسية. تساعد هذه الخاصية في تنظيم الكود بشكل أفضل وتعزيز إمكانية إعادة استخدامه.

### الاستخدام
عند تعريف فئة جديدة، يمكن استخدام "extends" للإشارة إلى الفئة التي يتم توسيعها. تكون الصياغة العامة كما يلي:

```scala
class SubClass extends SuperClass {
  // تعريف الخصائص والأساليب الخاصة بالفئة الفرعية
}
```

### التفاصيل
- يمكن لفئة واحدة فقط أن تمتد من فئة أخرى (وراثة فردية).
- يمكن أن تحتوي الفئات على أساليب وخصائص خاصة بها، بجانب تلك التي يتم وراثتها.
- يمكن استخدام "extends" مع الفئات المجردة (abstract classes) والفئات العادية.

## الأمثلة
### مثال 1: وراثة بسيطة
```scala
class Animal {
  def sound(): String = "Some sound"
}

class Dog extends Animal {
  override def sound(): String = "Bark"
}

val dog = new Dog()
println(dog.sound())  // الناتج: Bark
```

### مثال 2: وراثة مع الخصائص
```scala
class Vehicle {
  val wheels: Int = 4
}

class Car extends Vehicle {
  def info(): String = s"This car has $wheels wheels."
}

val car = new Car()
println(car.info())  // الناتج: This car has 4 wheels.
```

## الشرح
### الأخطاء الشائعة
- **عدم استخدام الكلمة المفتاحية**: إذا تم نسيان كلمة "extends"، ستظهر خطأ في التجميع (compilation error) حيث لن يتم التعرف على العلاقة بين الفئات.
- **تجاوز الأساليب بشكل غير صحيح**: عند استخدام `override`، يجب التأكد من أن الأسلوب موجود بالفعل في الفئة الأساسية.
- **المشاكل في الوراثة المتعددة**: سكالا تدعم الوراثة الفردية فقط، لذا يجب الانتباه عند محاولة وراثة أكثر من فئة واحدة.

### ملاحظات إضافية
- يمكن استخدام "extends" مع الفئات المجردة لتعريف فئة فرعية يجب عليها تنفيذ أساليب محددة.
- تعتبر الوراثة من الممارسات القابلة للنقاش في تصميم البرامج، لذا يجب استخدامها بعناية.

## ملخص جملة واحدة
تستخدم الكلمة المفتاحية "extends" في سكالا لتحديد العلاقات بين الفئات من خلال الوراثة، مما يعزز إمكانية إعادة استخدام الكود وتنظيمه.
