# 使用 "extends" 關鍵字的 Scala 繼承機制

## 概述
在 Scala 中，"extends" 關鍵字用於建立類別之間的繼承關係。透過這個機制，子類別可以繼承父類別的屬性和方法，促進代碼重用和擴展性。

## 文件說明
"extends" 關鍵字的主要目的是讓一個類別繼承另一個類別的功能。在 Scala 中，繼承可以讓開發者創建一個新的類別，該類別擁有父類別的所有特徵和行為，同時還可以添加或覆蓋這些特徵和行為。這使得代碼更加模組化和易於維護。

### 用法
在 Scala 中，使用 "extends" 關鍵字時，語法如下：

```scala
class 子類別名 extends 父類別名 {
  // 子類別的屬性和方法
}
```

這裡的 `子類別名` 是我們定義的新類別，而 `父類別名` 是我們希望繼承的類別。子類別可以使用父類別的屬性和方法，並且可以根據需要進行擴展或修改。

## 範例
以下是使用 "extends" 的基本示範：

```scala
// 定義一個父類別
class 動物 {
  def 發聲(): Unit = {
    println("動物發出聲音")
  }
}

// 定義一個子類別，繼承自動物
class 狗 extends 動物 {
  override def 發聲(): Unit = {
    println("狗汪汪叫")
  }
}

// 使用子類別
val 我的狗 = new 狗
我的狗.發聲() // 輸出：狗汪汪叫
```

在這個例子中，`狗` 類別繼承了 `動物` 類別，並覆蓋了 `發聲` 方法來提供特定的行為。

## 解釋
在使用 "extends" 時，有一些常見的陷阱和注意事項：

1. **單一繼承**：Scala 不支持多重繼承，即一個類別只能繼承一個父類別。但可以通過混合特徵（traits）來達成類似的功能。
   
2. **覆蓋方法**：當子類別覆蓋父類別的方法時，必須使用 `override` 關鍵字，否則編譯器會報錯。

3. **初始化順序**：父類別的主構造器會在子類別的主構造器之前執行，這意味著父類的屬性會先被初始化。

4. **抽象類別與特徵**：Scala 中的抽象類別和特徵提供了更靈活的繼承方式，值得深入學習。

## 簡單總結
"extends" 關鍵字在 Scala 中用於創建類別之間的繼承關係，允許子類別獲取父類別的屬性和方法，以實現代碼重用和擴展性。
