# استخدام كلمة "given" في لغة سكالا

## الملخص
تعتبر كلمة "given" في لغة سكالا من الميزات الحديثة التي تساهم في تسهيل كتابة الأكواد وتحسين قابلية القراءة. تُستخدم بشكل أساسي لتعريف القيم أو الصيغ التي يتم تمريرها تلقائيًا إلى الدوال أو الكلاسات التي تحتاج إليها.

## الوثائق
تُمثل كلمة "given" آلية جديدة لتسهيل تمرير القيم في سكالا، وتسمح بإنشاء سياقات استدلالية حيث يمكن لنظام سكالا استنتاج القيم المناسبة من خلال سياق الاستخدام. تُستخدم هذه الكلمة في التعريفات، حيث يمكن لمطوري البرامج أن يقوموا بتعريف قيم معينة كـ "given"، مما يسمح باستخدامها في جميع أنحاء الكود دون الحاجة إلى تمريرها بشكل صريح.

### الغرض
- تسهيل كتابة الأكواد وتقليل التعقيد.
- تحسين قابلية القراءة من خلال استنتاج القيم بشكل تلقائي.

### الاستخدام
يمكن استخدام "given" مع الدوال أو الكلاسات، وتُعد من أسهل الطرق لتعريف القيم التي يمكن استنتاجها من سياق الاستخدام. على سبيل المثال:

```scala
given Int = 42
```

هذا التعريف يعني أن أي دالة تحتاج إلى قيمة من نوع Int يمكنها استخدام 42 بشكل تلقائي دون الحاجة لتمريرها كوسيط.

## الأمثلة
### مثال 1: استخدام "given" مع دالة
```scala
trait Show[A] {
  def show(a: A): String
}

given Show[Int] with {
  def show(a: Int): String = a.toString
}

def printValue[A](value: A)(using showInstance: Show[A]): Unit = {
  println(showInstance.show(value))
}

printValue(10) // سيتم طباعة "10"
```

### مثال 2: تعريف قيمة "given"
```scala
given String = "Hello, Scala!"

def greet(using name: String): Unit = {
  println(name)
}

greet // سيتم طباعة "Hello, Scala!"
```

## الشرح
من الأمور الشائعة التي قد يواجهها المطورون عند استخدام "given" هي عدم فهم كيفية استنتاج القيم بشكل صحيح. يجب التأكد من أن السياق الذي يتم فيه استخدام "given" متوافق مع نوع القيمة. كما يجب الانتباه إلى أن "given" لا تعمل في جميع الحالات، بل يجب أن تكون هناك حاجة فعلية لنوع القيمة المعطاة.

## ملخص جملة واحدة
تُستخدم كلمة "given" في سكالا لتعريف القيم التي يمكن استنتاجها تلقائيًا، مما يسهل كتابة الأكواد ويعزز من قابلية القراءة.
