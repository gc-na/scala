# استخدام الكلمة المفتاحية "super" في لغة سكالا

## ملخص
تُستخدم الكلمة المفتاحية "super" في لغة سكالا للإشارة إلى الصف الأب (الأساسي) في سياق الوراثة. تساعد هذه الكلمة في الوصول إلى الدوال والخصائص المعرفة في الصف الأب، مما يسهل توسيع الوظائف في الصفوف المشتقة.

## الوثائق
تُعتبر "super" أداة قوية في البرمجة الكائنية (OOP) بلغة سكالا، حيث تسمح للمطورين بتجاوز الخصائص أو الدوال المتعارضة التي قد يتم تعريفها في الصف الفرعي. عند استخدامها، فإن "super" تشير إلى الكائن الخاص بالصف الأب، مما يمكن المطورين من استدعاء الدوال أو الوصول إلى الخصائص التي قد تكون مُخفاة في الصف الفرعي.

### الاستخدام
تُستخدم "super" في الحالات التالية:
- عند الحاجة إلى استدعاء دالة أو خاصية من الصف الأب.
- عند تجاوز دالة في الصف الفرعي ولكن الحاجة إلى تنفيذ جزء من دالة الصف الأب.

### التفاصيل
- **الدوال**: عند استدعاء دالة باستخدام "super"، يتم تنفيذ الكود من الصف الأب بدلاً من الصف الفرعي.
- **الخصائص**: يمكن أيضًا استخدام "super" للوصول إلى الخصائص المعرفة في الصف الأب.
  
## أمثلة
### مثال 1: استدعاء دالة من الصف الأب
```scala
class Parent {
  def greet(): Unit = {
    println("Hello from Parent")
  }
}

class Child extends Parent {
  override def greet(): Unit = {
    super.greet()  // استدعاء دالة الصف الأب
    println("Hello from Child")
  }
}

val child = new Child()
child.greet()
// الناتج:
// Hello from Parent
// Hello from Child
```

### مثال 2: الوصول إلى خاصية من الصف الأب
```scala
class Animal {
  val sound: String = "Generic Animal Sound"
}

class Dog extends Animal {
  override val sound: String = "Bark"
  
  def printSound(): Unit = {
    println(super.sound)  // الوصول إلى خاصية الصف الأب
  }
}

val dog = new Dog()
dog.printSound() // الناتج: Generic Animal Sound
```

## الشرح
من الأخطاء الشائعة عند استخدام "super" هو نسيان أنه يمكن استخدامه فقط للوصول إلى الدوال أو الخصائص المعرفة في الصف الأب. إذا لم تكن الدالة أو الخاصية موجودة في الصف الأب، سيؤدي ذلك إلى حدوث استثناء. كما يجب أن تكون حذرًا عند تجاوز الدوال، حيث قد يؤدي ذلك إلى سلوك غير متوقع إذا لم يتم استدعاء الدالة الأصلية بشكل صحيح.

## ملخص في جملة واحدة
تستخدم الكلمة المفتاحية "super" في لغة سكالا للإشارة إلى الصف الأب، مما يسمح بالوصول إلى الدوال والخصائص المعرفة في الصف الأب أثناء الوراثة.
